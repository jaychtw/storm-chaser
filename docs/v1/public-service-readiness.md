# Separate public-service readiness gate

**Not authorized or completed by V1-F.** A bounded local software package and accepted feature scope do not establish continuous public operation. $0 new expenditure remains binding; no account/service/hosting enrollment, main merge, public preview or deployment follows automatically.

| Gate | Current status / evidence needed before claiming it |
|---|---|
| Owner software/release acceptance | Pending V1-F review. A development push/private npm version is not a public release. |
| Delivery/hosting model | Conservative local-first only. Owner must explicitly choose/approve any operated service and verify costs against $0. Historical VM estimates are not quotes/budgets. |
| Persistent host/time/filesystem and service account | Real host resources, permissions, time sync, disk pressure and process isolation not verified here. No systemd unit installed/enabled. |
| Scheduling/reboot/long-running recovery | Static assets and isolated cursor/lease/crash regressions exist; actual timer catch-up/reboot and multi-day source changes need separate authorized observation. |
| Off-host backup/restore | Local online backup/new-directory restore tested. Independent host-loss restoration, encrypted destination/access and rotation not configured or proved. |
| Independent monitoring/alerts | Local health/diagnostics exist; independent uptime/data-age/disk/backup checks and delivery channel not activated. Source outage must not cause a restart loop. |
| Public edge/TLS/CSP/CORS/rate limits | Loopback-only API and local frontend tested. Public reverse proxy, TLS/domain, worker/CSP policy, abuse controls and traffic/load behavior unverified. |
| Current dependency/runtime security review | Locked graph/static/local checks recorded. Fresh advisory data, host patching, public exposure review and response/rollback procedures remain separate. Offline “0 findings” is not current vulnerability clearance. |
| Legal/attribution/release packaging | Source dossiers and dependency metadata retained. Public distribution notices/project licensing review and any changed source terms need owner review; no new reuse permission assumed. |
| Devices, accessibility, real user comprehension | Bilingual emulated layouts/keyboard/touch/axe and agent screenshot review recorded. Physical devices, screen readers and independent human comprehension remain unverified. |
| Release/rollback rehearsal and exact artifact | Reproducible local build/development commit exists. No public release/tag. Select a release artifact, retain good data/backup and prove authorized rollout/rollback separately. |

Deferred features (ranking, extra providers, comparisons, history and precise impact) are not additional blockers against the frozen software scope. Truthful coverage and limitations remain mandatory in any future delivery model. If reliable public operation cannot fit existing $0 resources, keep the supported local-first delivery; do not purchase or enroll a workaround automatically.
