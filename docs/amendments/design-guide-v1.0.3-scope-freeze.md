# Approved Design Guide amendment v1.0.3 — frozen local-first v1.0

2026-10-29 Asia/Taipei. **Approved product direction** from the [V1-F owner assignment](../briefs/v1-f-authorization.md); implementation/package/release acceptance remain separate. Supplements original Guide v1.0 and the M3-P amendment without overwriting historical text. [ADR 0004 v1.0](../adr/0004-v1-scope-freeze.md) is the scope-freeze decision.

## Product identity and adopted experience direction

**Storm Chaser v1.0 — JMA-first Experiential Cyclone Viewer.** Originality is principally in organization, presentation and interaction with lawfully usable existing public information, not producing proprietary observations or independent forecasts. This adopts the experience-first philosophy proposed in the M3-E amendment.

Forecast-Time Explorer is **accepted for inclusion in v1.0**, not merely a proposed POC. It explores exact discrete analyzed/forecast points in the currently selected advisory, with synchronized map emphasis, native source information, actual lead/valid/issue times and explicit variable intervals. No movement simulation, interpolated official position, impact prediction, confidence percentage or intensity conversion. Keyboard/mouse/touch, both locales, reduced-motion compatibility and honest expiry/staleness remain required.

## Frozen required scope

1. Interactive WNP/South China Sea regional map and official JMA analyzed/forecast centers.
2. Manual storm selection and neutral uncertain Auto, including when only one storm is available.
3. Forecast-Time Explorer, source-reported motion/intensity/validated native values and preserved missingness.
4. English/Traditional Chinese, accepted Night Operations identity, responsive map-first layout.
5. Attribution/provenance, original bulletin links and explicitly labeled official-chart page fallbacks.
6. Accurate collection/data states: current, stale-but-eligible, expired/excluded, partial and unavailable; archival storage is independent of display eligibility.
7. Local collection/archive/retention/recovery in the approved existing architecture, with supported installation and local operating instructions.

## Explicitly deferred from this version

Taiwan relevance ranking, CWA/JTWC integration, multi-agency comparison, historical cycle browsing/Time Travel, Forecast Showdown, precise impact/proximity, and additional perspective/disclosure features are deliberately deferred. The [register](../v1/deferred-capabilities.md) preserves their rationale and reopening criteria. Earlier v1.0 ranking/comparison goals no longer block this frozen scope and must not be described as completed.

## Delivery boundary

Conservative local-first software package on existing resources. Current version `1.0.0-rc.1` is a review candidate, not a public release. Software completion, owner release acceptance and continuous public-service readiness are separate. $0 new expenditure; no unattended weather collection, external enrollment/hosting activation, public preview/deployment or main merge. No changes to governing standards. Source/datum limitations and independent-warning disclaimer remain visible.
